# 部署:把成績寫進 Google 試算表(約 5 分鐘)

> 部署需要登入**你自己的** Google 帳號,請在自己的瀏覽器完成。帳號密碼不需要提供給任何人(包含 AI 助理)。

1. 建立新的 Google 試算表(名稱例如「資訊課程島成績」)。
2. 選單 **擴充功能 → Apps Script**。
3. 刪掉預設程式碼,貼上 [`backend/gas_code.js`](../backend/gas_code.js) 的全部內容,按 💾 儲存。
4. 右上角 **部署 → 新增部署作業**
   - 類型:**網頁應用程式**
   - 執行身分:**我**
   - 誰可以存取:**所有人**(學生不需登入 Google)
5. 按 **部署**,依指示授權(出現「Google 尚未驗證這個應用程式」時:進階 → 前往(不安全)— 這是你自己寫的指令碼)。
6. 複製 **網頁應用程式網址**(結尾是 `/exec`),貼到 [`config.js`](../config.js):
   ```js
   API_URL: "https://script.google.com/macros/s/xxxxxxxx/exec",
   ```
7. 重新整理網站,登入並完成一次測驗 → 試算表會自動出現:
   - `名冊`、`紀錄(全部)`
   - `班級703` 這類**依班級分開的分頁**(第一位該班學生交卷時自動建立)

## 之後修改 gas_code.js 要重新部署
Apps Script 修改後需 **部署 → 管理部署作業 → ✏️ 編輯 → 版本:新版本 → 部署**,網址不變。

## 注意事項
- 登入只有「班級、座號、姓名」,沒有密碼驗證:同學理論上可以輸入別人的資料作答。若之後需要防冒用,可加上簡易 PIN 碼。
- 網站是純前端,測驗答案在網頁原始碼中可被查看,適合形成性評量;正式期中期末考建議改在伺服器端批改。
- 網站要讓學生連得到,需放到網路上(如 GitHub Pages / 校內網頁空間),雙擊 index.html 只適合在單機測試。
